MSIME for Linux — bundled third-party notices
====================================================

This package embeds msime-engine at the locked revision recorded by engine-lock.json, which is installed in share/msime-client. The complete project license is the file named copyright in this directory. The Engine notice, the dictionary and helpcode notices, and the component license texts are installed beside this file.

Components compiled into the shared host library (libmsime_host_api.so, in the msime-client directory under the system library directory, for example lib/x86_64-linux-gnu/msime-client on Debian) include:

* msime-engine — GPL-3.0 and the notices supplied by the Engine distribution (msime-engine-GPL-3.0.txt, msime-engine-NOTICE.md, msime-engine-dictionary-NOTICE.md, msime-engine-dictionary-makecikudb-LICENSE.txt, msime-engine-helpcode-NOTICE.md).
* googlepinyinime-rev — Apache License 2.0 (Apache-2.0-googlepinyinime.txt).
* utfcpp — Boost Software License 1.0 (Boost-1.0-utfcpp.txt).
* The Engine voice capture module and miniaudio — the Engine voice license and miniaudio's MIT or public domain dual license (msime-engine-voice-LICENSE.txt, miniaudio-LICENSE.txt). whisper.cpp is not linked on Linux; speech recognition runs through the separately configured online provider.
* zinnia and the bundled handwriting model — the notices supplied with the Engine resources (Zinnia-LICENSE.txt, HandwritingModel-LICENSE.txt).
* OpenCC dictionaries used for Simplified/Traditional conversion — Apache License 2.0 (OpenCC-Apache-2.0.txt).
* The Rust crates the library is built from (serde, toml, sha2 and the rest of its dependency graph) — each crate's own license files, collected at package time (rust-crates-NOTICES.txt).

The desktop settings binary (msime-client-desktop, started by msime-client-settings) statically links its own Rust crate graph, including reqwest with rustls and the webpki-roots certificate data (CDLA-Permissive-2.0); those crates are in rust-crates-NOTICES.txt as well. Its embedded web frontend is bundled from npm packages (React, @tauri-apps/api and their dependencies), whose license files are in frontend-npm-NOTICES.txt.

The MCP server (msime-mcp) statically links its own Rust crate graph, including rmcp (the Model Context Protocol Rust SDK) and schemars; those crates are in rust-crates-NOTICES.txt as well.

Compiled into the native IBus engine, the provider programs and the Fcitx5 addon without a runtime package of their own:

* nlohmann/json, header-only — MIT (nlohmann_json-MIT.txt).
* Wayland protocol code generated by wayland-scanner from wlr-layer-shell-unstable-v1.xml (HPND-style permission notice, wayland-wlr-layer-shell-LICENSE.txt) and xdg-shell.xml from wayland-protocols (MIT, wayland-xdg-shell-LICENSE.txt), present when the build found wayland-client and xdg-shell.xml.

Dictionaries fetched after installation by msime-client-setup are verified against the installed desktop-dictionary.lock.json and keep their own notices beside them (for example mozc_dictionary_oss_README.txt for the Japanese dictionary); msime-engine-dictionary-NOTICE.md covers the Engine dictionary data those resources come from. This package ships no helpcode tables; the Engine reads them at run time from helpcodes/ in the resource directory when a host provides them, and msime-engine-helpcode-NOTICE.md applies to them.

Shared libraries such as IBus, Fcitx5, ICU, libcurl, SQLite, GTK and WebKitGTK are not bundled; they are loaded at run time from the distribution's packages, which carry their own copyright files.

The source tree retains each upstream notice. This collection is not a license-completeness or redistribution-authorization assessment; nested archives and distribution-specific dependencies must retain their own terms.
