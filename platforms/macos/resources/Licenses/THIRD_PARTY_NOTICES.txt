MSIME Client for macOS — bundled third-party notices
=====================================================

engine-lock.json. The complete project license is GPL-3.0.txt. The Engine
notice, dictionary and helpcode notices, and the component license texts are
included beside this file in the Licenses directory.

* ONNX Runtime, statically linked into the sherpa-onnx library as its inference backend — MIT License (onnxruntime-MIT.txt), with the notices of the components ONNX Runtime itself bundles in onnxruntime-ThirdPartyNotices.txt.

The speech recognition models are not part of this application; the settings page downloads them on request, and each model directory carries its own license.

The source tree retains each upstream notice. This collection is not a
license-completeness or redistribution-authorization assessment; nested
