# 全平台公共后端接入清单

范围：将已上线的公共 API 接到 Windows、macOS、iOS、Linux 的实际产品流程，补齐登录渠道配置、会话管理和显式同步。后端接口存在、客户端源码接入、合并发布、真实宿主验收分别记录，不互相替代。

## 必须完成

- [ ] Apple、Google、微信、手机、邮箱登录：渠道发现、挑战、凭据交换、取消、错误提示、资料、身份绑定、刷新、退出、注销账号。
- [ ] 各平台凭据存入系统安全存储；刷新并发协调、失效与退出清理；禁止共享设备令牌访问用户数据。
- [ ] 设置读取、版本冲突、明确选择上传/下载并应用可同步字段。
- [ ] 四类个人词库：目录、查询、增删改、文本导入导出、注音导入、增量变更；通过 Engine 应用到实际候选。
- [ ] 候选调频、固定位置、删除，跨端状态恢复、冲突与原子性；大快照使用有界流式文件传输。
- [ ] 剪贴板明确开启、显式添加、查询、去重、删除、清空和关闭；不默认上传系统剪贴板。
- [ ] 皮肤目录、资源、社区发布/下载/评分，校验后实际应用。
- [ ] 云候选、AI、翻译、批量和实时语音复用共通后端，保持取消、组合代次和失焦检查。
- [ ] 各输入查询、符号目录在相应产品入口可用，保持本地输入和离线回退。
- [ ] 各平台构建、协议集成测试、产品流程验收、PR 合并及发布；生产 Swagger/OpenAPI 保持关闭。

## 当前状态（2026-09-08）

- 后端 0.4.1 已上线；原有公共 API 抽取验收见 Backend 仓库 `docs/windows-api-extraction.md`。
- 线上 auth/providers：Apple 开启，Google、微信、手机、邮箱未开启。Apple 开启不代表真实账号登录验收通过。
- 已检查 Vault `msime-backend` 及 `common`、`notification`、`user` 的键名，没有发现可直接使用的新增登录渠道配置。不得挪用其他产品的 OAuth 客户端冒充本产品配置。
- 短信实现当前为阿里云短信，邮件实现为 SMTP；用户曾指明“短信用 Lark”，具体网关信息待确认。该配置问题不阻止其他客户端工作。
- Apple 独立工作区基于 develop 600625d，新增公共账号网络层并加入 iOS 构建输入；9 项 Swift 协议/会话测试、45 项项目配置测试、完整 iOS Simulator App 构建及账号入口 UI 测试通过。设置页已有账号入口、原生 Apple 登录、Keychain、刷新协调、昵称修改、退出与注销；真实签名账号登录及其余渠道/同步界面仍待完成。
- Windows、Apple、Linux 原工作区均有未提交适配与其他修改，保持原样。后续需逐项审查并将所需适配移到新基线，不能直接覆盖或把未提交代码当作已发布结果。

- iOS 已增加邮箱/手机号验证码登录页面：获取验证码、60 秒重发间隔、服务端有效期、取消和登录；入口只在渠道启用时出现。生产渠道仍关闭，尚无真实验证码验收。
- iOS 云剪贴板页面已接通明确开启/关闭、手动上传、搜索、复制、单条删除和清空。Swift 实际客户端连接生产 API 的同意、去重、特殊字符搜索、删除/关闭验收通过，临时账号与数据已清理；没有自动读取系统剪贴板。
